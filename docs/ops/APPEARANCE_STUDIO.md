# Appearance studio

Open **Connect → Experience → Themes and appearance**. The catalog includes 58 locally rendered presets plus the existing Light, Dark and Grey themes. Families include Apple, Ubuntu, Linux, Terminal, Monochrome, OnePlus, Nothing, Nature and Studio; names describe visual inspiration rather than vendor affiliation.

Search by name/family, filter a family, or save favourites. Preview opens a sample without changing the workspace; Apply saves the selected palette and its base brightness. Font, accent, corners, backdrop and motion can be customized independently. Fonts use installed fonts and local fallbacks; the package requires no font service or external assets. Reduced-motion system preference overrides decorative animations, and Off disables transitions and animations. Table rows are never animated into moving trading targets.

Visual settings are saved to the authenticated Sterling account database, with browser cache and an offline retry outbox. `sterling_appearance_v1` and `sterling_theme` remain cache keys. Sign-in restores account preferences before opening the workspace; pending writes are acknowledged or visibly reported as unsaved. First migration imports existing local settings once without overwriting an initialized account. Header light/dark switching remains available; incompatible custom palette overrides are removed when changing brightness. Classic buttons restore base palettes. Restore defaults returns all appearance preferences to Classic Light. The original layout, scale, loader and ticker settings remain available beneath the new section.

**Save, share & restore appearance** exports a copyable JSON package of visual settings only. Import validates IDs, font names, enums and six-digit hex accents before applying; it never accepts CSS or resource URLs. Trading settings, accounts and credentials are excluded. Imported classic packages retain their brightness. Restore does not alter broker or execution state.

Implementation: `frontend/src/appearance/catalog.ts`, `store.ts`, `AppearanceSettings.tsx`, App layout effect and shared CSS/Kite tokens. Chart effects subscribe to appearance settings so same-brightness palette changes refresh canvas colours. Green/red trade semantics retain the established tokens.
